# Castlist guide

How to use the features that Castlist adds on top of [AntennaPod](https://antennapod.org/). For everything else (subscribing, the queue, downloads, sync, and so on), the official [AntennaPod documentation](https://antennapod.org/documentation/) applies.

| Guide | What it covers |
|---|---|
| [Playlists](playlists.md) | Rule-based playlists: rules, playing, what happens at the end, automatic downloads, downloaded-only playlists, Android Auto |
| [Home screen](home-screen.md) | The playlists widget, playlist icons and app shortcuts |
| [Episode filter](episode-filter.md) | Basic and Advanced filters: which episodes download, and which ones playlists use |
| [Skip ad and the player](player.md) | The Skip ad button and the modern player |
| [Foldables and big screens](foldables.md) | Two-pane layouts, tabletop mode, episode details beside the list |
| [Backups](backups.md) | Backing up, restoring, and switching back to the official app |
| [FAQ](faq.md) | Common questions |

Something unclear or missing? [Open an issue](https://github.com/dcdude71/Castlist/issues).
